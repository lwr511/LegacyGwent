# Gascon’s Light Cavalry SP / 15280100 色差核对

结论：用户截图中闪卡偏黄绿、静态原图偏冷亮的主要差异，在源游戏提供的两类原始素材中就已存在。按用户要求保留源闪卡配色，不对本卡调色，不改游戏资源或构建。

核对来源为本机安装的 Thronebreaker。standard/high 的 15280000 是左侧静态参考；premium/high 和 premium/uber 的 15280100 是动态图集，两档动态源图都是偏黄绿的森林底色。

- 静态参考 PNG 与源静态贴图逐像素完全一致。
- 工程动态 PNG 与源动态 high 图集的单通道最大误差为 5/255；非透明像素 RGB 平均绝对误差分别约为 0.31、0.39、0.17/255，不存在能解释整幅明显冷暖变化的额外色偏。
- 10 个材质的全部源浮点和颜色参数与工程文件一致；客户端包中的这 10 个材质也再次核对一致。暖色假光参数来自原始材质，基础 _TintMainTex=(0.5,0.5,0.5,1) 与 shader 的乘二配套，并非误加暗色染色。
- 客户端包绑定正确的 15280100_23360_15280100 动态图集。包压缩后的 RGB 平均绝对误差仍分别仅约 0.67、0.65、0.85/255；个别压缩边缘像素最大误差为 52/255，未把压缩误差宣称为逐像素一致。
- 本卡预制体没有额外后处理脚本。背景 shader 直接输出纹理 RGB，UI 显示链也未添加本卡专属色温处理。
- 源 globalgamemanagers 与本工程的 m_ActiveColorSpace 都为 0（Gamma），没有两者色彩空间设置不一致的问题。

证据：source-textures.json、source-verification.json、parameter-check.json、packaged-verification.json；同目录 PNG 是直接解码的源贴图/包内贴图。此次未运行源游戏定位到这张牌进行最终帧对照，因此结论限定为源素材、参数和现有包绑定的核对，不宣称源游戏所有运行时画面逐像素一致。
