## 本地素材恢复

Git 不包含提取素材，因此仅检出本提交不能重建完整动态卡内容。需要原有合法取得的客户端素材和对应转换结果。四个片段的最小修复可用纯 Python 标准库重复执行：

```powershell
python work/DynamicCards/repair_euler_orders.py
python work/DynamicCards/repair_euler_orders.py --apply
```

默认只检查；`--apply` 先验证四个文件的结构与曲线数量，再备份并只修改欧拉曲线顺序。可传 `--project` 指定 Unity 项目。随后在 Unity 刷新资产，并通过 `Tools > Dynamic Cards > Build Options > 仅构建动态卡资源包` 重建。

完整重导入应先用本提交中的 `decode_*_animations.py` 重新生成动画数据，再重建控制器契约并运行 SourceAnimationImporter。解码工具沿用当前本机来源路径，并依赖 UnityPy、NumPy 及已有 source_effects/卡号清单；这些本地输入不包含在提交中。旧契约缺少旋转顺序时不能直接交给新导入器。现场三套契约共 722 条欧拉轨道均已补齐顺序。
