# 原版赛尔奇克：静态画、模型、贴图和动画对照

本次先学习原版 `20161800 / 20161801`。湖女制作已暂停，失败版本未保留在正式 catalog 中。本说明记录亲自在 Unity 中渲染和检查过的结果；DSH 负责资源引用追踪，Codex 负责运行、几何/UV 检查与纠错。

## 看到的模型

移除贴图、原材质属性与后处理后，单独渲染原版头部。鼻梁、眼窝、嘴和下颌都有真实几何起伏。线框来自同一个原版 mesh。

![原版头部侧面白模](C:/UnityProjects/LegacyGwent/work/PremiumStudySeltkirk/head-clay-side.png)
![原版头部侧面线框](C:/UnityProjects/LegacyGwent/work/PremiumStudySeltkirk/head-wire-side.png)

原版是为卡牌观看方向制作的低面数立体网格：部分背面开放，场景同时使用平面/分层几何。它既不是整张画贴在一块板上，也不能据此描述成完整的 360° 角色。主体 mesh 还包含背景部分，不能拿整个 mesh 的包围盒厚度当人体厚度。

| 网格 | 顶点 / 三角面 | 有正权重的骨骼数 | 多骨骼权重顶点数 |
|---|---:|---:|---:|
| `_1_Mesh` | 1425 / 1765 | 36 | 354 |
| `_1_Head` | 166 / 273 | 17 | 72 |
| `_2_Head2` | 150 / 259 | 17 | 72 |
| `HelmFireRefl` | 48 / 76 | 1 | 0 |

这些数字从 Unity 的实际网格、三角索引和 BoneWeight 读取。Renderer 的 60 个骨骼引用不等于每个网格实际受 60 根骨骼影响。

## 贴图怎样对应模型

动态卡使用独立的 1024×1024 图集 `20161801_13952_20161801.png`，不是静态卡图 `20161800.png`。图集将正常脸、变身脸、胸甲、肩膀、前臂、腿、剑、前景头盔、天空和帐篷分开摆放；网格的 UV 分别读取这些区域。

下面的线条是从原网格 UV 和三角索引绘制的：青色为主体，黄色为正常头部，粉色为替代头部。

![原版动态卡图集与真实 UV](C:/UnityProjects/LegacyGwent/work/PremiumStudySeltkirk/atlas-with-actual-uv.png)

这解释了前一版湖女为什么失败：粗略的人体网格配整张人物图投射，不能自动得到正确的关节、侧面和头发纹理。前视图与卡画是否贴合、转动后是否露出错误贴图、关节是否连续，都必须逐项验收。这里能验证成品的 UV/材质结构；现有文件不能还原原作者在美术软件中每一步制作顺序。

## 手、剑和动画

剑位于主体网格的一个独立连接块中：16 个顶点，均以 100% 权重跟随右腕骨。剑光与灵魂特效另挂在右腕下。原版这只手保持握持，没有展示张手、脱离、接剑过程，不能假定复制这张牌的绑定就能完成湖女的接剑动作。

实际运行的控制器引用 8 个动画片段；Intro 长约 2.967 秒，Loop 长 9 秒。身体和面部骨骼动画、替代脸溶解、天空/身体颜色变化、剑光、火焰和其他粒子共同构成演出。正常头与替代头使用独立网格和溶解材质，而不是重新生成每一帧图像。

## 下一步的验收门槛

1. 先做湖女的静止模型与分区 UV；正面轮廓、脸、手、头发和剑的位置必须对上已批准卡图，小角度侧看无破面和穿插。
2. 再验证张手与握手所需的手指几何、骨骼和权重；需要另找原版手指动作案例，不能把赛尔奇克的腕骨握剑当作已解决。
3. 静止模型与局部变形通过后，才制作“高处落剑—触底前抓住—提回卡图位置”的动画，最后接入循环、原版特效/音频和收藏交互。

本次已验收原版学习场景和上述可见证据，未验收湖女人物模型、接剑动画或最终效果；没有将失败版本当成完成品。

最终运行复查：场景实际载入 5 个蒙皮渲染器、3 个 Animator、20 个粒子系统；自动诊断截图关闭。退出 Play 后原资源读取从临时开启恢复为关闭，质量等级保持运行前的 High。运行前后快照为 `status-before.json` / `status-playing.json` / `status-after.json`，位于下述 work 目录。
