# 详情页合成与收藏筛选

收藏页只负责浏览和筛选。打开未解锁闪卡的详情页后，卡牌下方显示合成价格与按钮；普通版本不显示合成入口。合成继续通过原服务器接口处理，动画附着在当前详情卡牌及已有收藏卡牌上，完成后隐藏按钮，不增加返回历史。

“普通 / 闪卡 / 全部”为版本筛选；“已拥有”为可叠加的开关。所有普通卡视为已拥有，闪卡由账号的 OwnedCards 决定。例如“闪卡 + 已拥有”只显示已合成的闪卡；新账号选此组合可得到空列表。

按钮资源直接提取自本地旧客户端 `Gwent_Data/StreamingAssets/AssetBundles/gui/spriteatlases/high/buttons`：`btn_square_idle/hovered/down/toggle_frame` 和 `btn_wide_idle_300/hovered_300/down_300/inactive_300`。拥有图标 `db_filter_owned_owned` 来自 `spriteatlases/high/deckbuilder`。沿用已有的三种原版 premium 筛选图标。提取时处理图集旋转，保留原图像及 Unity 元数据。

原版 `UICardPreviewPrefab` 包含 `TransmuteEvent` 和底部 `Buttons` 容器，当前实现复用其详情页布局和原版按钮素材；没有声称整个收藏页面已逐像素复刻。

验收时使用正常的本地服务，在 Unity 登录场景 Play 模式下检查筛选组合、详情入口、真实合成扣费、双击防重、灰度解除、导航历史和关闭后重开详情。

大卡旋转：收藏页右侧预览和详情页共用归一化限位，水平为 ±0.7、垂直为 ±1/3（原来均为 ±1），外框持续旋转对应水平 ±4.9°、垂直 ±0.5°。自动运动也使用缩小后的范围。按住拖动接管自动运动，松手回正后恢复。右侧预览在可见卡框绑定拖拽入口，拖动越过卡牌列表时不切换预览。

2026-09-15：Unity 实际验收 33 项通过，其中 16 项分别覆盖详情页和右侧预览的自动运动、输入命中、双向限位、拖动接管、释放和自动恢复。
