# 客户端多语言补齐与验证（2026-09-19）

当前配置支持 English、中文、Русский、Polski。本次新增功能均使用现有 `MenuLocales` / `CardLocales` 语言系统，不再使用“中文，否则英文”的分支。

## 本次修复

- 每日任务：主菜单入口、标题、每日登录、小局胜利、倒计时、UTC+8 重置说明、王冠进度、三档奖励、到账/未完成状态、余额、同步错误、完成提示和关闭按钮。
- 闪卡收藏：普通/闪卡/全部/已拥有筛选、粉尘余额、持有数量、合成价格、合成中、重试、数量已满、余额不足及失败提示。
- 卡牌详情与设置：战力、返回、关闭、语音、动态卡开关；修复金币显示选项和通用设置选项切换语言后的刷新。
- 其他 UI：排行榜名次、观战房间编号和标题、赛季无数据状态与时间单位、结算分数、登录连接/状态、饰品更新提示、新奖励弹窗、排行榜详情表头、卡组名称占位提示。
- 内容缺漏：俄文赛季称号、俄文/波兰文卡牌标签、中文经典杰洛特与段位边框名称、波兰文卡组删除提示参数；补齐 70018 的三种缺失语言，以及俄文卡牌中混入的英文/波兰文、占位名称和背景描述。
- 公告：中文公告不再被英文分支覆盖；俄文与波兰文增加对应公告。旧服务器暂不提供新公告接口时，客户端使用所选语言的内置公告。异步返回的旧语言公告不会覆盖后续语言选择。

玩家名称、卡组名称等用户输入保持原样；专有名词、精灵语台词、吼声及本来没有描述的饰品不作为漏译。开发日志、编辑器工具和未使用的测试样例不属于玩家 UI。

## 语言包与缓存

三处语言包同步修复：

1. `src/Cynthia.Card.Unity/src/Cynthia.Unity.Card/Assets/Resources/Locales`：内置包。
2. `src/Cynthia.Card.Unity/src/Cynthia.Unity.Card/Assets/StreamingFile/Locales`：本地文件包。
3. `src/Cynthia.Card/src/Cynthia.Card.Server/Locales`：服务器下载包。

每种语言均有 **837 个菜单词条、682 个卡牌条目**。保留服务器原有的卡牌平衡描述差异，仅补齐本次翻译缺漏。界面固定文本保留词条键和参数，切换语言时重新读取；新建界面读取当前语言。

旧下载包缺少词条时，回退到**同一种语言**的内置词条，同时保留服务器已有卡牌描述。新服务器通过 `GetGameLocalesVersion` 返回语言内容哈希；客户端使用独立的 `LocalizationContentVersion` 检测翻译更新，不再依赖卡牌规则版本变化。旧服务器仍兼容原有版本检测。

共用输入框预制体同时用于登录、搜索和匹配密码，翻译由所属场景决定，避免模板上的固定翻译覆盖其他用途。
