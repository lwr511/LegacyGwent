# 闪卡原位合成修正

2026-09-14，按用户指定的“一种牌只合成一次、普通/闪卡相邻、灰度卡原位变动态”规则修改。

## 交互与呈现

- 默认显示成对的普通卡与闪卡，普通在左、闪卡在右。不用三份库存或三次付费来表达铜卡闪卡资格。
- 未拥有闪卡采用真正的灰度 shader，覆盖卡图、卡框和阵营徽章；普通版本仍彩色静态。原来的加深彩色以及底部菱形占有标记已移除。
- 点击灰度闪卡选中它，在收藏页点击合成；后台成功确认后，在原卡框内播放光效。右侧选中卡的预览同步原位变化。
- 不创建屏幕中央的卡、不遮住整个收藏页、不重建列表、不重置滚动位置。原位升级过程中保留已加载灰度卡，动态第一帧准备好后显示彩色动态版本，避免短暂空白或侧边预览重新飞入。
- 成功后隐藏额外的合成/选用步骤。正常展示的普通版作为对照，加入普通版本不会关闭账号已经选用的闪卡。服务端按卡 ID 解锁一次，所有卡组里的三张同名铜卡共用。
- 普通组牌数量限制仍保留；闪卡条目不显示 X3 作为拥有/合成计数。缺少可合成动态资源的条目仍显示对照版本，但不可扣费合成。

## 原版参考边界

继续使用本地旧客户端 `CraftPremium` 的部分纹理和关键时间点：`HandleCardUpdate` 约 2.9667 秒、`DisableObject` 6.6 秒。视觉效果用当前 Unity UGUI 实现，现已局限在卡框内。

没有直接运行整个旧客户端粒子预制体，没有移植该事件的声音，也没有与原客户端同分辨率录像做逐帧比较。因此本次完成的是原位交互和呈现修正，不应宣称整套原版特效或 UI 已经逐像素还原。
